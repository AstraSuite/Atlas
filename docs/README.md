# Atlas documentation

The [README](../README.md) covers installing, running and configuring Atlas. These pages
are for people working on it.

- [Contributing](CONTRIBUTING.md): getting set up, building, the CI checks, and the
  conventions a change should follow.
- [Architecture](architecture.md): how the C++ singletons and the QML tree fit together,
  where state is stored, and what runs off the UI thread.
- [Navigation](navigation.md): the address bar, search, the three file views and
  type-ahead.
- [Shortcuts](shortcuts.md): the rebindable shortcut registry, view-local keys, and adding
  an action.
- [File operations](file-operations.md): copy, move, the clipboard, image paste, the trash
  and undo.
- [Opening files](opening-files.md): default applications, Open With, `mimeapps.list` and
  terminal applications.
- [Custom actions](custom-actions.md): user scripts and service menus in the context menu.
- [Theming](theming.md): the Material 3 palette, Caelestia's scheme, tokens, fonts and
  Papirus folder colours.
